# 掌握标准（mastery-checklist）

## 七项清单

- [ ] **问题**：一句话说清这块解决什么
- [ ] **图示**：能画 ≥3 框的架构/序列图
- [ ] **方法**：每个核心函数能讲清干什么、谁调谁
- [ ] **参考**：能找到官方 doc 或 deep_search_pro 对应模式
- [ ] **改坏**：能解释一次改错设计/关键行的后果
- [ ] **面试**：三句话
- [ ] **追问**：能答 1 道追问题

**≥5/7 才可进入下一文件/Phase 或写新功能。**

## 结构化过关附加项

讲完一个文件后，用户应能回答：

1. 文件里几个类、几个全局单例？
2. 从浏览器连 WS 到 monitor 推送，经过哪几个函数？（按顺序）
3. 任选本文件一个核心方法，说明「若改坏关键一行会怎样」

## 逐行模式（可选）

仅当用户要求「逐行」时：

1. 指定段内关键行能白话解释
2. 段末自检完成再下一段

## 面试三句话模板

1. 要解决什么问题
2. 方案是什么
3. 最难的坑是什么
